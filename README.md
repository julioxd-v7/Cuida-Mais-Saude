# CUIDAR MAIS

Plataforma que conecta pessoas que precisam de cuidados a cuidadores profissionais verificados. É um projeto acadêmico de Leandro Ferreira, Júlio Vinícius, Pablo Malveira e Luiz Miguel Martiniano.

| Pasta | Conteúdo |
|---|---|
| [`app/`](./app) | Aplicativo mobile (React Native + Expo + TypeScript) |
| [`backend/`](./backend) | API (Node.js + TypeScript + PostgreSQL/Supabase) |
| [`docs/`](./docs) | Auditoria, arquitetura, roadmap e guia de execução |

**Começar:** [`docs/COMO-EXECUTAR.md`](./docs/COMO-EXECUTAR.md)

**Situação:** Parte 3a (profissões, verificação com documentos, selo e suporte) implementada. Próxima: Parte 3b, pedido de atendimento no estilo Uber, chat cliente ↔ profissional e avaliações. Veja [`docs/ROADMAP.md`](./docs/ROADMAP.md).
